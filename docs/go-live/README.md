# VerdisChain Go-Live Readiness

## Purpose

This directory contains the evidence, checklists and readiness gates required before VerdisChain mainnet launch and any public VRDX token offering.

## Hard Launch Rule

No mainnet launch or public token sale should be authorized while any applicable P0 legal, security, operational or technical gate remains unresolved.

## External Dependencies

The following require qualified external professionals or executive authorization:

- UAE / VARA legal review
- EU / MiCA VRDX classification
- Global jurisdiction review
- Legal entity formation
- KYC/AML provider selection and compliance implementation
- Independent security audit
- Air-gapped production key ceremony
- Final executive launch authorization

## Technical Readiness

The project team must verify:

- Genesis configuration
- Validator configuration
- Consensus configuration
- Runtime and pallet consistency
- Tokenomics consistency
- DEX safety
- Staking and slashing
- Governance and upgrade controls
- Key-management procedures
- Disaster recovery
- Incident response
- Independent security audit remediation

## Evidence Standard

A readiness item is not considered complete merely because documentation exists.

Each completed gate must have verifiable evidence such as:

- code/test results;
- configuration;
- signed legal opinion;
- executed agreement;
- audit report;
- ceremony report;
- provider contract;
- or authorized executive sign-off.

## Sensitive Material

Never commit:

- private keys;
- seed phrases;
- passwords;
- API secrets;
- KYC/PII;
- production credentials.

Production validator and multisig private keys must be generated and handled through the approved air-gapped key ceremony.

## Status

This document is a readiness framework only. It does not constitute legal, regulatory or security certification.
