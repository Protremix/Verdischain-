Getting Started

Quick Start Guide

Get up and running with a local Verdis node and deploy your first smart contract in under 3 minutes.

01

Install Node

Clone the official Verdis Chain repository and compile the native Rust Substrate binary using Cargo.

git clone https://github.com/verdis-chain/node.git && cargo build --release
02

Run Dev Chain

Launch a local single-node development blockchain with instant block production and pre-funded accounts.

./target/release/verdis-node --dev --tmp --rpc-port 9944
03

Deploy Contract

Install the Verdis JavaScript SDK or CLI to deploy Rust pallets and EVM smart contracts seamlessly.

npm install @verdis/sdk && verdis-cli deploy --network devnet

Rust Pallet vs. Solidity Contract

Compare native Substrate Rust pallet implementation with standard EVM Solidity smart contract deployment.

🦀 carbon_pallet.rs (Substrate Rust)
// carbon_pallet.rs - Substrate Rust Pallet #[frame_support::pallet] pub mod pallet { use frame_support::pallet_prelude::*; #[pallet::storage] pub type RetiredCredits<T: Config> = StorageMap< _, Blake2_128Concat, T::AccountId, u128, ValueQuery >; #[pallet::call] impl<T: Config> Pallet<T> { #[pallet::weight(10_000)] pub fn retire_credits( origin: OriginFor<T>, amount: u128 ) -> DispatchResult { let who = ensure_signed(origin)?; RetiredCredits::<T>::mutate(&who, |v| *v += amount); Self::deposit_event(Event::CreditsRetired(who, amount)); Ok(()) } } }
💎 GreenCarbon.sol (EVM Solidity)
// SPDX-License-Identifier: MIT pragma solidity ^0.8.20; import "@openzeppelin/contracts/token/ERC20/ERC20.sol"; contract GreenCarbon is ERC20 { mapping(address => uint256) public retiredCredits; event CreditsRetired(address indexed account, uint256 amount); constructor() ERC20("Verdis Offset", "VCO") { _mint(msg.sender, 1_000_000 * 10**18); } function retire(uint256 amount) external { _burn(msg.sender, amount); retiredCredits[msg.sender] += amount; emit CreditsRetired(msg.sender, amount); } }
