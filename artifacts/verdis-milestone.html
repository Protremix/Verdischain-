Key Fixes Applied

1. DEX/Eco Route Registration
Routes checked if (this.dex) in constructor before modules were injected. Fixed by moving route setup to separate methods called from setDEX()/setEco().
2. Transaction Signature Verification
tx.from stored address but verify() needed public key. Added publicKey field to Transaction type.
3. @noble/secp256k1 v2.x hmacSha256Sync
sign() required etc.hmacSha256Sync which was undefined in v2.x, causing silent fallback to fake signatures. Fixed by setting it with @noble/hashes/hmac.
