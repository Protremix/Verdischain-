# VERDIS CHAIN — REFERRAL PROGRAM REVIEW

**Created:** 2026-08-14
**Updated:** 2026-08-14
**Decision:** REMOVED per Rojs Gordons' instruction

---

## BACKGROUND

The Verdis Chain website included a referral program page (/referral/) offering bonus VRDX tokens for referring new participants.

## CONCERNS

1. No legal review of referral terms
2. Potential classification as a pyramid scheme in some jurisdictions
3. MiCA compliance not verified
4. Referral bonus structure contradicted "no bonus" policy elsewhere
5. Program had not been legally reviewed by any counsel

## DECISION

**Rojs Gordons instructed removal on Aug 14, 2026.**

Actions taken:
- All footer links to /referral/ removed from 27 web pages
- /referral/ page replaced with "Discontinued" notice
- This document records the decision

## STATUS

RESOLVED. Referral program is discontinued and no longer linked from any page.
