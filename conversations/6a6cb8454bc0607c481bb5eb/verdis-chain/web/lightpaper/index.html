Overview

What is Verdis Chain?

The core thesis in one paragraph.

Verdis Chain is a designed for energy efficiency Layer-1 blockchain built on Substrate, powered by native Delegated Proof-of-Stake (DPoS) consensus. It combines an integrated AMM decentralized exchange (DEX), ink! smart contracts, on-chain carbon credit tracking, green validator scoring, and reforestation logging into a single protocol. The native token VRDX has a fixed supply of 100 billion (9 decimals) and serves as gas, staking asset, governance instrument, and medium of exchange. Verdis Chain connects to EvolvixOS, an AI Engineering Operating System that provides smart contract auditing, AI-powered development tools, and a plugin marketplace.

Technology

Architecture

The technical stack that powers Verdis Chain.

Consensus Layer

DPoS with BABE/GRANDPA finality. 21 target validators, all powered by 100% renewable energy. Green validator scoring rewards eco-friendly operators with higher block production priority. Slashing mechanism penalizes malicious behavior with configurable severity.

Smart Contracts

ink! smart contracts compiled to WASM via pallet_contracts. Substrate-native, no EVM compatibility layer needed. Every contract is automatically analyzed by EvolvixOS AI before deployment, with security scores published on-chain.

AMM DEX

Native automated market maker built directly into the protocol. 6 liquidity pools (VRDX/ECO, VRDX/CARBON, VRDX/TREE, VRDX/GREEN, ECO/CARBON, VRDX/REDD). Constant product formula with overflow-protected arithmetic and deadline parameters.

Eco Layer

Carbon credit minting, retirement, and tracking directly on-chain. Green validator scoring, reforestation project logging, and CO2 offset verification. Integration with satellite imagery and IoT sensors for autonomous verification via EvolvixOS AI.

Cross-Chain

IBC protocol for cross-chain communication with Polkadot, Cosmos, Ethereum, and BSC. Wrapped VRDX with 1:1 protocol-level backing. Future ZK rollup for 10,000+ TPS scaling.

Ecosystem

The EvolvixOS Connection

AI meets blockchain — the dual ecosystem vision.

Verdis Chain

Provides decentralized trust, value transfer, smart contracts, and on-chain carbon credits. The blockchain infrastructure layer.

EvolvixOS

Provides AI-powered smart contract auditing, automated security analysis, development tools, and a plugin marketplace. The AI intelligence layer.

How They Connect

Every smart contract deployed on Verdis Chain is automatically analyzed by EvolvixOS before execution. Security scores and vulnerability reports are published on-chain. AI models analyze governance proposals and simulate economic impact. Together, they form a complete green technology stack: blockchain provides trust, AI provides intelligence.

Developer Ecosystem

JavaScript SDK (51 methods, native WebSocket), REST/GraphQL APIs, CLI tools, developer documentation, and a 5B VRDX grant program for third-party builders.
