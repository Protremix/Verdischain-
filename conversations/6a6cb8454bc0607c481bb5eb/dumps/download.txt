Android Installation Guide
Download the APK file by tapping "Download APK" above
Open the downloaded file in your file manager
If prompted, enable "Install from unknown sources" in Settings
Tap "Install" and wait for installation to complete
Open Verdis Wallet and create a new wallet or import an existing one
Set up your 6-digit PIN and enable biometric authentication
Back up your recovery phrase — this is the only way to recover your wallet

⚠ Never share your recovery phrase with anyone. Verdis will never ask for it.
