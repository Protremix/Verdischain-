Introduction

Verdis Chain is a Substrate-based blockchain built with a native Delegated Proof-of-Stake (DPoS) consensus mechanism, an integrated AMM decentralized exchange (DEX), and a comprehensive eco-system featuring carbon credit tracking, green validator scoring, and reforestation logging.

Key Features
Native DPoS Consensus — 14 validator slots, green score weighting, delegate/stake mechanism
AMM DEX — Constant-product automated market maker built into the chain runtime
Eco System — On-chain carbon credits, reforestation logging, green validator scoring
EVM Compatibility — 143 opcodes including Cancun upgrade (TLOAD, TSTORE, MCOPY)
Solana-Inspired Features — Gulf Stream mempool, Turbine block propagation, ZK compression, ALT
IBC Support — Cross-chain communication via Inter-Blockchain Communication protocol
