Platform Features

Everything you need to build on green infrastructure

From consensus to smart contracts to carbon tracking — Verdis Chain delivers a complete blockchain ecosystem.

⛓️

Native DPoS Consensus

Delegated Proof of Stake with BABE block production and GRANDPA finality. Validators earn green scores based on energy efficiency and carbon offset commitments.

BABE + GRANDPA
🔄

AMM Decentralized Exchange

Native Automated Market Maker built directly into the chain. Swap tokens, provide liquidity, and earn fees without external smart contracts.

Native AMM DEX
🌱

Carbon Credit Tracking

On-chain carbon credits, green validator scoring, and reforestation logging. Every transaction contributes to a verifiable environmental impact record.

Eco Pallet
⚡

EVM Smart Contracts

143 EVM opcodes including Cancun upgrades (TLOAD, TSTORE, MCOPY). Deploy Solidity contracts with Chain ID 909 and 24KB max code size.

143 Opcodes · Chain 909
🛡️

Tokenomics & Vesting

100B total supply with 12B investor allocation enforced on-chain. Vesting schedules, transfer restrictions, and mint/burn controls built into the protocol.

100B Supply · 12B Vesting
🏗️

Substrate + Rust Core

Built from scratch in Rust using the Substrate framework. WASM runtime, gRPC/JSON-RPC support, and benchmarked weight files for all pallets.

Rust · Substrate · WASM
