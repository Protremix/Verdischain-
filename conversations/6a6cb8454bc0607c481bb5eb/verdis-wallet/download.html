Installation Instructions

  1. Download the APK — Tap the download button above or scan the QR code with your phone camera.
  2. Allow unknown sources — Android may ask permission to install from unknown sources. Tap "Allow" or go to Settings → Security → Enable "Unknown Sources".
  3. Install — Open the downloaded file and tap "Install".
  4. Create or import wallet — Launch the app and create a new wallet or import an existing one with your private key.
  5. Get VCO tokens — Use the faucet on the dashboard at verdischain.com/dashboard to claim free VCO tokens.
