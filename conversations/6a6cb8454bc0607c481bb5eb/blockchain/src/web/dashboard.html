📡 Network Configuration

Add Verdis to Trust Wallet as a custom network:

Network NameVerdis
RPC URLhttp://localhost:3200/rpc
Chain ID909 (0x38d)
SymbolVRS
Decimals18
Explorerhttp://localhost:3200

🔑 Wallet Import

Import a Verdis wallet into Trust Wallet using the private key below. Since Verdis uses secp256k1 (same as Ethereum), the same private key works in both.

📋 Setup Instructions

Step 1: Open Trust Wallet → Settings → Networks → Add Custom Network

Step 2: Enter the Network Configuration above (RPC URL, Chain ID 909, Symbol VRS)

Step 3: Go to Settings → Wallets → Import Wallet → Private Key

Step 4: Paste the private key from one of your Verdis wallets above

Step 5: Your VRS balance will appear in Trust Wallet!
