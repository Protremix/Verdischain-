Introduction

DPoS Consensus

Verdis Chain uses a native Delegated Proof-of-Stake consensus mechanism with 14 validator slots. Validators are weighted by their green score — an eco-friendly metric that rewards sustainable operations.

Validator Registration

// Register as a validator dpos.registerValidator(origin, prefs)?; // Delegate stake to a validator dpos.delegate(origin, validator_address, amount)?; // Undelegate dpos.undelegate(origin, validator_address)?; // Claim rewards dpos.claimRewards(origin)?;

Green Score System

Each validator has a green score (0-100) that affects their selection probability. Validators with higher green scores receive more block production opportunities.

Green Score Calculation

Green scores are updated via the Eco pallet's updateGreenScore call, which considers: renewable energy usage, carbon offset contributions, reforestation participation, and network uptime.

EVM Layer

Verdis Chain includes a full Ethereum Virtual Machine implementation with 143 opcodes, including the Cancun upgrade (TLOAD, TSTORE, MCOPY, BLOBHASH, BLOBBASEFEE).

Chain Configuration

chain_id: 909 max_code_size: 24576 gas_limit: configurable per transaction

Supported Opcodes

The EVM pallet supports all standard opcodes plus:

  • Cancun — TLOAD (0x5C), TSTORE (0x5D), MCOPY (0x5E), BLOBHASH (0x49), BLOBBASEFEE (0x48)
  • Comparison — SGT (0x13), SLT (0x12), GT (0x11), LT (0x10)
  • Stack/Memory — MSTORE, MLOAD, RETURN, REVERT, STOP, ADD, SUB, MUL, DIV
  • Environmental — CALLER, CALLVALUE, CALLDATASIZE, CALLDATALOAD

123 EVM-specific tests verify opcode correctness across the full instruction set.

AMM DEX Pallet

The AmmDex pallet implements a constant-product automated market maker (x*y=k) directly in the chain runtime, eliminating the need for smart contracts for basic swaps.

Operations

FAQ

What is Verdis Chain?

Verdis Chain is a Substrate-based blockchain with native DPoS consensus, an integrated AMM DEX, and an eco-friendly design featuring carbon credit tracking, green validator scoring, and reforestation logging.

What is the VRDX token?

VRDX is the native token with a 100 billion total supply and 9 decimals. It's used for transaction fees, staking, governance, and DEX liquidity.

How do I become a validator?

Use the DPoS pallet's registerValidator extrinsic to register. You'll need a minimum stake and a green score to be selected for block production.

Is the EVM fully compatible?

Yes. The EVM pallet supports 143 opcodes including the Cancun upgrade. You can deploy Solidity smart contracts directly. Chain ID is 909.

How do I get testnet tokens?

Use the faucet at verdischain.com/faucet/ to request testnet VRDX tokens.

What is the green score?

The green score (0-100) measures a validator's environmental impact. Higher scores increase block production probability. Scores are updated through the Eco pallet based on renewable energy usage, carbon offsets, and reforestation participation.
