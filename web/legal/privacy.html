Privacy Policy

Last updated: August 7, 2026

1. Overview

Verdis Chain is a public blockchain platform. This Privacy Policy explains how we handle data in connection with our web services (wallet, DEX, explorer, faucet, documentation) hosted at verdischain.com.

2. Data We Do Not Collect

  • Private keys or seed phrases — These are generated and stored locally in your browser (localStorage). They never leave your device.
  • Personal identification — We do not require KYC/AML verification for testnet usage.
  • Email addresses — Not required to use any service.
  • IP addresses for tracking — We do not track or profile users by IP.

3. Data That Is Public (On-Chain)

As a public blockchain, the following data is visible to everyone via the explorer:

  • Wallet addresses (sr25519 public keys)
  • Transaction amounts and recipients
  • Block contents and timestamps
  • Validator addresses and green scores
  • AMM pool reserves and swap history
  • Carbon credit minting events
  • Reforestation logging data

This data is immutable and cannot be deleted. It is an inherent feature of blockchain technology.

4. Technical Data We Process

4.1 Server Logs

Our nginx web server automatically logs:

  • IP addresses (for security/rate limiting only, not stored long-term)
  • Request timestamps
  • Requested URLs and HTTP methods
  • User-Agent strings
  • Response status codes

Logs are used for security monitoring (Fail2Ban), rate limiting, and debugging. They are rotated and deleted after 7 days.

4.2 Local Storage

The web wallet stores the following in your browser's localStorage:

  • Mnemonic seed phrase (encrypted with your browser's origin)
  • Account address
  • Transaction history (local only, not synced)

This data never leaves your browser. Clearing your browser data will permanently delete your wallet access.

4.3 Cookies

We do not use tracking cookies. Grafana (at /grafana/) uses a session cookie for authentication, but this is internal-only and not exposed to regular users.

5. Data Sharing

We do not sell, share, or transfer user data to third parties. Blockchain transaction data is inherently public and visible to all network participants.

6. Data Security

  • HTTPS/TLS 1.3 encryption for all web traffic
  • HSTS preload enabled
  • Content Security Policy (CSP) headers
  • UFW firewall (only ports 22, 80, 443, 30333-30341 open)
  • Fail2Ban intrusion prevention
  • SSH key-only authentication
  • Rate limiting on all endpoints
  • RPC filter proxy for external access

7. Your Rights (GDPR)

Under GDPR, you have the right to:

  • Access — Request a copy of any personal data we hold (server logs)
  • Rectification — Request correction of inaccurate data
  • Erasure — Request deletion of server log data (on-chain data is immutable and cannot be deleted)
  • Portability — Request export of your data in machine-readable format
  • Objection — Object to processing of your data
  • Withdrawal — Withdraw consent at any time

To exercise these rights, contact: privacy@verdischain.com

8. Children's Privacy

Verdis Chain is not directed at children under 13. We do not knowingly collect data from children. If you believe a child has provided personal data, contact us for immediate deletion.

9. International Data Transfers

Our servers are located in Germany (Hetzner Cloud, Nuremberg). Data may be processed in the European Union. We comply with EU data protection regulations including GDPR.

10. Changes to This Policy

We may update this Privacy Policy periodically. Changes will be posted on this page with an updated date.
