Become a Validator

Join the Verdis Chain validator set and start earning rewards.

1

Meet Requirements

Minimum requirements to register as a validator:

  • 10,000 VRDX minimum stake
  • 4-core CPU, 8GB RAM, 100GB SSD
  • 99% uptime requirement
  • Stable internet (50+ Mbps)
  • Green energy commitment (optional, boosts score)
2

Register On-Chain

Submit a validator registration transaction:

  • Generate session keys
  • Submit register_validator extrinsic
  • Set commission rate (0–20%)
  • Declare green energy source
  • Wait for next epoch rotation
3

Start Earning

Once active, earn rewards every block:

  • Block rewards proportional to stake
  • Eco bonus from green score
  • Commission from delegators
  • Carbon credit NFTs for eco practices
  • Leaderboard bonuses for top validators
