Introduction

The Verdiscan API provides structured, queryable access to Verdis Chain on-chain data. It wraps the Substrate JSON-RPC into clean REST endpoints, pre-decoding extrinsics, categorizing transactions, and indexing validator and DEX data.

The API is organized into eight domains: Block, Transaction, Account, Token, Validators, DEX, Eco, and Network.

Base URL

https://verdischain.com/api/v1

All endpoints are relative to this base URL. Responses are JSON.

Authentication

Note: During testnet, all endpoints are publicly accessible without an API key. Mainnet will require API key authentication via the X-API-Key header.

For future mainnet access, include your API key in the request header:

# Mainnet (future)
curl -X GET "https://verdischain.com/api/v1/block/last" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Accept: application/json"

Block

GET /block/last Get latest blocks ›

Returns the latest blocks on Verdis Chain, sorted by block number descending.

Query Parameters
ParamTypeDescription
limitnumberNumber of blocks to return (1-100, default 20)
Try it: GET /block/last?limit=5
Example Response
{
  "success": true,
  "data": [
    {
      "block": 599,
      "hash": "0x601281...0620cb",
      "parent_hash": "0x644e8c...af1084",
      "extrinsics": 2,
      "timestamp": "2026-08-07T18:25:01Z"
    }
  ],
  "count": 1
}
GET /block/{block_number} Get block detail ›

Returns full block detail including extrinsics, digest logs, state root, and extrinsics root.

Path Parameters
ParamTypeDescription
block_numbernumberBlock number (e.g., 599)
Try it: GET /block/599
GET /block/{block_number}/transactions Get block transactions ›

Returns decoded extrinsics/transactions within a specific block.

Try it: GET /block/599/transactions

Transaction

GET /tx/last Latest transactions ›

Returns the latest transactions across recent blocks, decoded with pallet/call info.

ParamTypeDescription
limitnumberNumber of transactions (1-100, default 20)
Try it: GET /tx/last?limit=10
GET /tx/{hash} Transaction detail ›

Returns full transaction detail by hash, including decoded call data, signer, block info, and event logs.

Try it: GET /tx/0x0000

Account

GET /account/{address} Account detail ›

Returns account balance, nonce, and identity information.

ParamTypeDescription
addressstringSS58 address (e.g., 5GrwvaEF...)
Try it: GET /account/5GrwvaEF...
GET /account/{address}/transactions Account transactions ›

Returns transactions associated with an account (as signer or involved party).

ParamTypeDescription
limitnumberResults per page (1-100, default 20)
pagenumberPage number (default 1)
GET /account/{address}/transfers Account transfers ›

Returns transfer history (VRDX token transfers) for an account.

Returns all AMM DEX pools with reserves, fees, and volume.

Returns node health, version, name, and chain properties.

Try it: GET /network/status

SDK & Integration

JavaScript

// Simple fetch example
const res = await fetch('https://verdischain.com/api/v1/block/last?limit=5');
const data = await res.json();
console.log(data);

Python

import requests

res = requests.get('https://verdischain.com/api/v1/block/last',
  params={'limit': 5})
data = res.json()
print(data)

curl

  -H "Accept: application/json"
