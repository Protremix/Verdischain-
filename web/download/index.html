Android Installation Guide

  1. Download the APK file by tapping "Download APK" above
  2. Open the downloaded file in your file manager
  3. If prompted, enable "Install from unknown sources" in Settings
  4. Tap "Install" and wait for installation to complete
  5. Open Verdis Wallet and create a new wallet or import an existing one
  6. Set up your 6-digit PIN and enable biometric authentication
  7. Back up your recovery phrase — this is the only way to recover your wallet

⚠ Never share your recovery phrase with anyone. Verdis will never ask for it.
